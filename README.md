# Data Science Projects

This repository contains selected data science projects focused on solving real-world business problems using data-driven approaches.

## Project Overview

Each project follows a structured workflow:
- Problem definition and business context
- Data cleaning and exploratory analysis
- Feature engineering and model development
- Evaluation using appropriate metrics
- Insights, limitations, and next steps

## Projects

- **Customer Churn Prediction**  
  Predicting customer churn using classification models to support retention strategies.

- **Fraud Detection**  
  Detecting fraudulent transactions with imbalanced data techniques.

- **Demand Forecasting**  
  Time series forecasting for demand planning and inventory optimization.

## Tools & Technologies
Python, Pandas, NumPy, Scikit-learn, SQL, Matplotlib, Seaborn
