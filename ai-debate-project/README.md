# Multi-Agent RAG-Based AI Debate System

This project demonstrates a document-driven AI debate system where two LLM agents engage in structured discussions grounded in user-provided knowledge using Retrieval-Augmented Generation (RAG).

## Key Features
- Multi-agent LLM debate with role-based personas
- Retrieval-Augmented Generation (RAG) using external documents
- User-controlled document upload and debate setup
- Interactive Gradio-based web interface

## Tech Stack
Python, LlamaIndex, HuggingFace Embeddings, Groq LLM, Gradio
